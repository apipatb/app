# ✨ Version 2.3 Features

## 🎉 What's New in v2.3

### 1. 🔐 JWT Authentication System

Complete authentication system with access and refresh tokens!

**Features:**
- ✅ User registration with password hashing (bcrypt)
- ✅ Login with JWT access tokens (15 min expiry)
- ✅ Refresh tokens for extended sessions (7 day expiry)
- ✅ Token blacklisting on logout
- ✅ Password change functionality
- ✅ Profile management (get/update)

**Endpoints:**
```bash
POST /api/auth/register      # Register new user
POST /api/auth/login         # Login and get tokens
POST /api/auth/logout        # Logout and invalidate tokens
POST /api/auth/refresh       # Refresh access token
GET  /api/auth/me            # Get current user profile
PUT  /api/auth/me            # Update current user profile
POST /api/auth/change-password # Change password
```

**Example:**
```bash
# Register
curl -X POST http://localhost:3000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "name": "John Doe",
    "email": "john@example.com",
    "password": "password123",
    "phone": "0812345678"
  }'

# Login
curl -X POST http://localhost:3000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "john@example.com",
    "password": "password123"
  }'

# Response
{
  "success": true,
  "user": {
    "_id": "...",
    "name": "John Doe",
    "email": "john@example.com",
    "role": "user"
  },
  "tokens": {
    "accessToken": "eyJhbGciOiJIUzI1NiIs...",
    "refreshToken": "eyJhbGciOiJIUzI1NiIs..."
  }
}

# Use token in requests
curl -X GET http://localhost:3000/api/customers \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

### 2. 👥 Role-Based Access Control (RBAC)

Three user roles with different permissions:

**Roles:**
- **User** - Can create orders, view own data
- **Staff** - Can manage orders, view all data
- **Admin** - Full access to all resources

**Route Protection:**
```javascript
// Public routes
GET /api/orders/:id             # Anyone can view order details

// Authenticated routes
POST /api/orders                # Any logged-in user can create order

// Staff/Admin only
PUT /api/orders/:id             # Only staff/admin can update orders
PATCH /api/orders/:id/status    # Only staff/admin can change status
GET /api/dashboard/*            # Only staff/admin can view dashboard

// Admin only
DELETE /api/orders/:id          # Only admin can delete orders
DELETE /api/customers/:id       # Only admin can delete customers
```

**Authorization Check:**
```bash
# Will fail with 403 Forbidden if user doesn't have required role
curl -X DELETE http://localhost:3000/api/orders/123 \
  -H "Authorization: Bearer USER_TOKEN"
```

### 3. 🔌 WebSocket Real-Time Updates

Socket.io integration for real-time order tracking and dashboard updates!

**Features:**
- ✅ Real-time order status updates
- ✅ Order tracking by order number
- ✅ Dashboard live updates (staff/admin)
- ✅ User-specific notifications
- ✅ JWT authentication for Socket.io
- ✅ Automatic reconnection

**Connection:**
```javascript
// Frontend example
import { io } from 'socket.io-client';

// Connect with authentication
const socket = io('http://localhost:3000', {
  auth: {
    token: 'YOUR_JWT_TOKEN'
  }
});

// Track specific order
socket.emit('track-order', 'ORD2501000001');

// Listen for order updates
socket.on('order-update', (data) => {
  console.log('Order updated:', data);
  // {
  //   orderNumber: 'ORD2501000001',
  //   type: 'status-changed',
  //   oldStatus: 'pending',
  //   newStatus: 'processing',
  //   timestamp: '2025-01-05T10:30:00.000Z'
  // }
});

// Dashboard updates (staff/admin only)
socket.emit('join-dashboard');
socket.on('dashboard-update', (data) => {
  console.log('Dashboard update:', data);
});

// Stop tracking order
socket.emit('untrack-order', 'ORD2501000001');
```

**Events:**
```
Client → Server:
  - track-order        # Start tracking an order
  - untrack-order      # Stop tracking an order
  - join-dashboard     # Join dashboard room (staff/admin)
  - ping               # Keep-alive ping

Server → Client:
  - order-update       # Order status/data changed
  - dashboard-update   # Dashboard data changed
  - notification       # User-specific notification
  - broadcast          # System-wide announcement
  - tracking-started   # Confirmation of tracking start
  - tracking-stopped   # Confirmation of tracking stop
  - pong               # Keep-alive response
```

### 4. 🔒 Enhanced Security

**Password Security:**
- bcrypt hashing with 12 salt rounds
- Minimum 6 character passwords
- Password comparison via secure methods
- Password change tracking

**Token Security:**
- Short-lived access tokens (15 minutes)
- Long-lived refresh tokens (7 days)
- Token blacklisting on logout
- Redis-based token storage
- JWT signature verification

**Input Sanitization:**
- express-mongo-sanitize (prevents MongoDB injection)
- express-validator (comprehensive input validation)
- Joi schemas for all endpoints
- Custom validation messages

**Protected Routes:**
- All customer routes require authentication
- All order creation/updates require authentication
- Dashboard routes require staff/admin role
- Delete operations require admin role

## 🚀 Getting Started

### 1. Environment Setup

Update your `.env` file:

```bash
# Existing variables
NODE_ENV=development
PORT=3000
MONGODB_URI=mongodb://localhost:27017/laundry_db
REDIS_HOST=localhost
REDIS_PORT=6379
CACHE_TTL=3600
LOG_LEVEL=info

# NEW: JWT Configuration
JWT_SECRET=your-super-secret-jwt-key-change-this-in-production-min-32-chars
JWT_ACCESS_EXPIRY=15m
JWT_REFRESH_EXPIRY=7d

# NEW: CORS (optional)
CORS_ORIGIN=*
```

**Important:** In production, use a strong JWT_SECRET (min 32 characters)!

### 2. Install Dependencies

```bash
npm install
```

New dependencies installed:
- jsonwebtoken (JWT tokens)
- bcryptjs (password hashing)
- socket.io (WebSocket)
- express-mongo-sanitize (input sanitization)
- express-validator (validation)

### 3. Start Server

```bash
# Development
npm run dev

# Production
npm start
```

Output:
```

✅ Connected to MongoDB
✅ Connected to Redis
✅ Pub/Sub initialized
✅ Socket.io initialized successfully
🚀 Server is running on port 3000
📍 API available at http://localhost:3000
📊 Dashboard: http://localhost:3000/api/dashboard
🔌 WebSocket server ready
💚 Health check: http://localhost:3000/health
```
